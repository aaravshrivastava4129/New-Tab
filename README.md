# **New-Tab**

A custom browser new tab page that brings NASA's Astronomy Picture of the Day into your everyday browsing.

Instead of opening a plain browser tab, this replaces it with a space-themed dashboard featuring a daily NASA image, clock, calendar, search, and quick shortcuts.

Click <a href="https://aaravshrivastava4129.github.io/New-Tab/">here</a> to see demo.

---

# The Idea

I wanted to make a new tab page that felt more personal than the default browser new tab.

The main idea was to use NASA's daily astronomy image as the background and build the rest of the interface around it. The result is a simple space-themed page that changes with NASA's daily image while still keeping the things I use regularly in one place.

---

# Features

- Daily NASA Astronomy Picture of the Day as the background
- Live local time and date
- Personalized greeting
- Search bar for quick web searches
- Quick-access shortcuts
- Mini calendar showing the current month
- NASA image information link
- Glassmorphism-style interface
- Responsive layout
- Custom settings popup for entering your name
